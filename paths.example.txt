# 路径清单（示例文件）
#
# 真实清单是内部资料，不进这个公开仓库（但结构完全一样：一行一个路径）。
# 程序只认清单里出现的路径，其余的都不进表。以 # 开头的行是注释，空行忽略。
#
# 注意四件事：
# 1) 这是 du 的路径（子目录），不是 df 的挂载点（/data /dev /mnt 那种）。
# 2) 内部表格的写法是"没有前导斜杠"的，而 du 的输出带前导斜杠。
#    → 所以匹配时必须先归一化，否则一条都匹配不上（而且不会报错）。
# 3) 只放"稳定"的路径：/data/app/~~NAiKwIaegG3g... 这类混淆目录每次安装都变，
#    今天写进清单，明天就命中不了。**包名（com.xxx）是稳定的，可以写死。**
# 4) /data/data 和 /data/user/0 是同一个目录的两种路径（实测大小完全一样），
#    只列一个；否则表格里会出现两行一模一样的数字，看起来像 bug。
