| `top_n()` | 按占用排序，看哪个目录最占地方 | 调试时想知道"谁最占空间" | `int()`、`sort(key=)`、`lambda`、**字符串排序 vs 数字排序** |

**坑：** ① 示例清单和数据同源 → 命中率 100%，**是同义反复，绿得没信息**；② `yield` 让函数变生成器 → 没有 `len()`（签名承诺 `list` 却没给）；③ `sort` 按字符串排会错（`"9" > "100"`）。

**一句话：测试如果和数据同源，它永远绿，而且什么都没验证。**

## 2026-10-21（三）—— 两次采集 + 增长%

| 新增的东西 | 作用 | 解决了什么问题 | 用到了什么 |
|---|---|---|---|
| `parse.growth()` | 把两次采集按路径对齐，算出每条路径的增长% | 手工算增长会错，前值为 0 会出 `#DIV/0!` | `dict` 建索引、`set` 合并键、`sorted`、除法 + `None` 表示"不可计算" |
| `main.check_device()` | 开跑前查：设备在不在、`/data` 读不读得到 | 读不到数据时只抛原始异常，人不知道该怎么办 | `try/except`、返回码、**人话报错的三段式（现象/原因/处理）** |
| `save_snapshot()` / `load_snapshot()` | 一次采集存成 JSON，第二次能和它对比 | 两次采集之间没有记忆，无法比较前后 | `json.dump/load`、`os.makedirs`、`datetime`、**用"清单路径"当稳定键** |
| `--stage before/after` + 自动对比 | 一条命令区分前后，`after` 自动找当天 `before` 出增长表 | 靠人记"这次采的是前还是后、上次存哪了" | `sys.argv`、`sys.exit` 退出码、日期命名 |
| 4 条 `growth` + 4 条 `top_n` 测试 | 锁住"增长四种情况"和"排序" | 改代码时不知道弄坏没弄坏别的 | pytest、边界值分析、`_rows()` 测试小工具 |

**坑：**
1. **索引写反**：`row[0]` 是大小、`row[1]` 是路径 —— 测试用 `ValueError` 当场抓住
2. **函数没写 `return`** —— 报错是 `assert None == [...]`；**Python 里没 return 就是安静地返回 `None`**
3. **元组要双括号** —— `append((a, b, c, d))`：外括号是函数调用，内括号是"打包成一个整体"
4. **PowerShell 的反引号是转义符**（我用正则改文件时把自己坑了）

### 一句话

**示范（AI 版）：系统最危险的状态不是"崩了"，而是"安静地给了你一个错的结果"。**

> 今天它出现了三次，同一个形状：
> 1. `growth()` 没写 `return` → 返回 `None`，**不报错**（代码沉默）
> 2. 0 字节的样本/快照文件 → **存在、名字对、内容是空的**（数据沉默）
> 3. 采集时 stdout 为空、错误在 stderr → **不看 stderr 就当成"采到了"**（采集沉默）
>
> **你这工具里所有"多余"的设计都在对抗它**：启动自检、命中率、未命中清单、
> `before = 0` 写 `None` 不写 `0`、失败带原始报错退出、测试锁住"不可计算"。
>
> **面试可以这么说：**"我做这个工具最大的收获是：**系统最危险的状态不是崩溃，是安静地给出错误结果**。
> 所以我在每一层都把它显式化——采集前自检、采集后报命中率、缺失写 None 不写 0、失败时带原始报错退出。
> 因为空表和真数据看起来一模一样。"

**你的：今天最值的是 `growth()` 这一块——**它一个函数里同时用到了**字典**（建索引）、**集合**（合并两边的路径）、**列表 + append**、**循环**、**判断（三种边界情况）**、**排序**，还有 `int()` 转换和 `None` 表示"不可计算"。

> **以前这些是零散的知识点；今天它们第一次被一个真需求绑在一起，必须同时在场才能跑通。**
> **这是我短期补基础密度最大的一块。**

**为什么"一个函数塞 7 个知识点"比"上 7 节课"有效：**
教程把知识切成互不相干的章节（这才是"学了不会用"的原因）；**真需求不给这个便宜——它要求它们同时在同一个函数里协同工作。**
所以那句老话是对的：**你不是"学会了 Python 再去做工具"，你是"做工具的时候，Python 自己长出来了"。**
